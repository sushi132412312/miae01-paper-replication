# 本模块接口与后续集成边界

## 已实现接口

`src.models.build_model(method, seed, config, synthetic=False, cache_dir=None)`返回RoBERTa二分类模型。method为ft/lora；synthetic=True要求status=synthetic_selfcheck，构造2层、hidden32、4头、vocab97的小模型。

LoRA配置必须含正整数lora_r、有限正数lora_alpha，拒绝bool。正常模式不接受rank0或alpha0消融；若未来需要消融，应另定义明确协议。seed为[0,2**32)内整数。非法配置统一抛ValueError。FT不要求LoRA参数。

LoRA仅注入Query/Value，Key保持普通Linear；只训练A/B和classifier。FT全部可训练。初始化A为Kaiming uniform、B为零，merge_weights=False。

`parameter_report(model)`返回总量、可训练量、低秩量、分类头量、冻结量、共同主干/分类头/冻结张量哈希、可训练参数名及LoRA模块名。

`src.model_support.seed_everything(seed)`同步Python/NumPy/Torch种子。`tensor_hash(named_tensors)`对名称、dtype、shape和连续CPU字节求SHA256，名称重复报ValueError。float32格式兼容前轮Mac诊断；不要据此推断与缺失原common算法等价。不同设备/库版本不承诺逐位相同。

## 本轮没有实现的共同接口

src.common、src.data、src.train、src.evaluation没有被猜写。真实分支仍需原src.data.validate_real_config，再按model_id/model_revision加载安全格式预训练权重；缺件时明确失败。本模块不决定SST-2版本、正式训练规模、最优轮次或三种子协议。

原测试要求run(config, method, output, synthetic=True)导出预测、manifest、指标和冻结检查；这些属于共同训练入口，本次不以新写同名函数冒充实现。

逐例预测字段由原产物可见：run_id,method,seed,checkpoint,sample_id,gold_label,predicted_label。后续按ID复算并拒绝重复/缺失/非法标签/混合上下文；FT/LoRA应共用验证清单。种子统计应至少3个不同训练种子、相同协议/验证集，报告样本标准差n-1。

LoRA保存/恢复应包括训练过的分类头。官方lora_state_dict默认只导出A/B，不能单凭它推定完整分类模型可以恢复。
